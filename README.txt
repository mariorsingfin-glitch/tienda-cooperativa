CRENERGÍA V3
1. Descomprima el ZIP.
2. Reemplace los archivos del repositorio GitHub por estos archivos en la raíz.
3. Confirme los cambios en main.
4. Abra la web la primera vez agregando ?v=3 al final.
5. En Android use Chrome > menú > Instalar aplicación.

Esta versión incluye:
- Acceso simulado Cliente/Administrador.
- Inicio del cliente con cuatro tarjetas.
- Simulador FV interactivo.
- Ajuste por superficie y presupuesto.
- Dashboard del administrador.
- Parámetros, costos y tarifas editables durante la sesión.

Limitación: todavía no existe base de datos ni autenticación real.
