ESTIMADOR FV CRENERGÍA VERSIÓN 3 - GITHUB PAGES

1. Elimine del repositorio los archivos anteriores de la aplicación.
2. Suba estos archivos directamente a la raíz del repositorio:
   index.html
   manifest.webmanifest
   service-worker.js
   icon-192.svg
   icon-512.svg
3. Settings > Pages
4. Source: Deploy from a branch
5. Branch: main
6. Folder: / (root)
7. Espere a que Actions muestre el despliegue con marca verde.
8. Abra: https://USUARIO.github.io/NOMBRE-REPOSITORIO/

Si aparece una versión vieja:
- Abra en incógnito, o
- borre los datos del sitio github.io en Chrome,
- luego vuelva a cargar.

IMPORTANTE: los archivos deben estar directamente en la raíz, no dentro de una subcarpeta.
